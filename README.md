# 🍳 Chef Claude – AI Recipe Generator

Chef Claude is a **full-stack AI web application** built with **React** on the frontend and **Node.js + Express** on the backend. Users enter a list of ingredients and get a complete, formatted recipe generated by an AI model.

The project started as a frontend-only learning exercise and was later refactored into a **monorepo full-stack architecture** — with a secure backend, MongoDB database, and Google OAuth authentication.

🌐 **Live Demo:** [Chef Claude](https://chef-claude-react-five.vercel.app)

---

## 🚀 Features

### Recipe Generation
- Add multiple ingredients dynamically
- Delete ingredients individually
- Duplicate and empty input prevention
- Serving size selector (1 / 2 / 4 / 6 people)
- Generate recipes using Groq AI (Llama 3.1)
- Vegetarian-safe logic *(recipe stays vegetarian unless non-veg ingredients are detected)*

### Export & Share
- Copy recipe to clipboard
- Save recipe as Image
- Download recipe as PDF

### Auth & History (Login Required)
- Google OAuth login — no password needed
- Recipe history — view your last 5 generated recipes
- Save favourites — heart any recipe to mark it
- Dedicated history page with modal recipe viewer

### General
- Secure API key handling via backend (key never exposed to browser)
- Rate limiting — max 10 recipe generations per 15 minutes
- Fully responsive UI, styled with Tailwind CSS v4
- 404 page for unknown routes

## 🔧 Setup & Run Locally

### Prerequisites
- Node.js v18+
- A free [Groq API key](https://console.groq.com)
- A free [MongoDB Atlas](https://mongodb.com/atlas) cluster
- Google OAuth credentials from [Google Cloud Console](https://console.cloud.google.com)

### 1. Clone the repository

```bash
git clone https://github.com/vidhisonani/chef-claude-react.git
cd chef-claude-react
```

### 2. Set up the Backend

```bash
cd backend
npm install
```

Create a `.env` file inside `backend/`:
```env
GROQ_API_KEY=your_groq_api_key_here
MONGODB_URI=your_mongodb_connection_string
FRONTEND_URL=http://localhost:5173
GOOGLE_CLIENT_ID=your_google_client_id
GOOGLE_CLIENT_SECRET=your_google_client_secret
GOOGLE_CALLBACK_URL=http://localhost:5000/auth/google/callback
JWT_SECRET=your_jwt_secret_here
```

Start the backend server:
```bash
npm run dev
# Server runs on http://localhost:5000
```

### 3. Set up the Frontend

Open a new terminal:
```bash
cd frontend
npm install
```

Create a `.env` file inside `frontend/`:
```env
VITE_API_URL=http://localhost:5000
```

Start the frontend:
```bash
npm run dev
# App runs on http://localhost:5173
```
